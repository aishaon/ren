# Rangpur Entrepreneurs Network (REN)

## Project Overview
REN is a modern, hybrid platform designed for the entrepreneurs of Rangpur. It combines an organizational website, a multi-vendor marketplace, and a community engagement system. The platform provides a professional digital space for business growth, networking, and commerce.

## Tech Stack
- **Frontend:** HTML5, TailwindCSS (CDN-based)
- **Primary Aesthetic:** 'Editorial Clean' (White space, serif typography, minimalist couture layouts).
- **Secondary Aesthetic:** 'Modern Luxury' (Dark mode, mesh gradients, Outfit font).
- **Responsiveness:** Fully responsive across all devices.

## Project Structure
- `/`: Project root containing all 32 HTML templates.
- `/assets/`:
    - `/css/`: Custom styles.
    - `/js/`: Client-side logic.
    - `/img/`: Project images.
- `GEMINI.md`: Project-specific instructions and architecture (this file).
